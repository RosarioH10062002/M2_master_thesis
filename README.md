In the `01_experimental_design` folder, you will find everything necessary to run the SART paradigm, including the preliminary screening phase (SART with feedback and trial SART).

In the `02_data_participants` folder, you will find the data collected from the 14 participants during the screening process, followed by the longitudinal experimental data from the six selected participants. Anonymized participant metadata are also available. Additional consent forms are stored in the private GitLab repository.
